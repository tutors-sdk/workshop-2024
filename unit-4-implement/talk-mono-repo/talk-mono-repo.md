# Monorepo Architecture

A comprehensive visual walkthrough of the Tutors monorepo structure, covering the technology stack, JSR subsystem (model, time, gen, tutors), Svelte package ecosystem, applications, services, and deployment workflows.

## Key Topics

- Repository structure and architectural layers
- JSR packages for course generation
- Svelte packages for UI and services
- Applications (reader, catalogue, live)
- PartyKit real-time infrastructure
- Data flow and dependency graphs
- Development and deployment strategies
